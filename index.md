# **Reflections on Markdown** 
##### By Gavin Jones
### *Markdown is often viewed as a simple way to format text. However, its development shows bigger questions about how technical standards are created. Its syntax was designed to make writing for the web more accessible, while still keeping the source readable as plain text. Markdown's lack of a single formal grammar creates ambiguities that became more important as the format spread to new communities. Examining Markdown's structure and evolution help to demonstrate how a simple writing tool can develop into an important piece of digital infrastructure.*
### *To indicate document structure, Markdown uses ASCII punctuation characters. A steam-oriented, hierarchical document model implies when the format is able to handle things like paragraphs, headers, lists, links, emphasis, and code, but struggles with things like tables, footnotes, and metadata. Formal specification allows anyone to write Markdown without having to learn a complete syntax. However, it can also leave many edge cases undefined. The consequences of using regular expressions rather than a formal grammar is that it can cause inconsistent behavior across implementations. It can also cause performance vulnerabilities. Prioritizing the human reader of the source file helps it relate to the parsing ambiguities that later motivated CommonMark.*
### *John Gruber's emphasis on borrowing conventions from email, usenet, and earlier plain text formats reveals that it was key to shaping the way communities would work to become infrastructural. This was because the use of blockquotes with >, emphasis with asterisks, and setext headers. Markdown has exceeded far beyond its design for web writers. It has now spread into note-taking, documentation, academic writing, and AI training data/output. Open standards and simplicity allow people to adapt them into unplanned, new problems. Gruber gave Markdown away under a BSD license because it wasn't designed as a standalone commodity. The gift economy of open source depends on a large scale of capital, privilege, and externalized costs, which is something that we might not see.*
